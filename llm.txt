1.When a model gives you a wrong citation with total confidence, what do you think went wrong inside it?

The model isn't explicitly deciding “I don't know, so I'll make something up.
It is continuing the sequence based on what is statistically plausible given the context it has.
A wrong citation can therefore be generated by the same mechanism that generates a correct citation.
RAG can reduce this problem by supplying relevant external information, but it does not magically guarantee correctness.
The model can still misinterpret, omit, or contradict the retrieved information.
